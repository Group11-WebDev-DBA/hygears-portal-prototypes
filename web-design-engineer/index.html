How borrowing works

Read the borrowing rules
  1. 1 Reserve online Start here Pick an item and your dates. You get a reference number like HYG-2026-0142.
  2. 2 Officer review Pending An officer approves or declines. Check it anytime on Track Request.
  3. 3 Pick up Approved Show your reference number at pickup room to confirm.
  4. 4 Return Done Bring tools back by the return date. Consumables are used up.
