Before you borrow

Who can borrow from Hygears?

PUP students with a project. An officer approves each request before pickup.

What is the difference between a tool and a consumable?

Tools come back by your return date. Consumables, like zip ties, are yours to use up.

How do I know my request was approved?

Every request gets a reference number like HYG-2026-0142. Enter it to see where your request stands.
