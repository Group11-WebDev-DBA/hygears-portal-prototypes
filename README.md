# Hygears Web Portal: prototypes

Design prototypes for the Hygears Web Portal (Web Development final project, Group 11, BSIT 3-2).
Each folder is the same 7 pages built with a different design skill, so the group can pick a direction before building the real PHP + MySQL site.

**Open online:** https://group11-webdev-dba.github.io/hygears-portal-prototypes/

- `index.html`: picker page with all directions
- `BRIEF.md`: what every prototype had to include and follow
- `BRAND.md`: Hygears brand notes from their Facebook page
- `QA-PROTOCOL.md`: the role-played QA visits; each folder has its own `QA.md` and `NOTES.md`

Prototypes only: forms don't send data anywhere yet. Item lists, counts and announcements are samples.
